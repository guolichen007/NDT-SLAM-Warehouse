## P0 根因链（三层）

`FIRST_CONFIRMED_BAD_STAGE = HAZARD_AUTHORITY_TO_SAFETY_STATUS_HANDOFF`

1. **CargoFrameDecision 旁路**：`positive_warning_confirmed_this_frame=false` 时直接
   `authorized=true` 返回，Code29（review episode，常为 confirmed=false）旁路
   authoritative hazard identity 检查。
2. **selectReviewHazard distance 判定过宽**：只排除 `distance < 0`，残留点
   `distance == 0` 通过 valid 判定。
3. **29 review geometry 来源缺失**：live 分支仅当 `selected_source_evidence` 非空
   才填充 geometry；为空时 `has_cluster_evidence=false`，SafetyStatus 的
   distance/clearance 保持默认 0。
