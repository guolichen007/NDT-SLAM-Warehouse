## Revision Reasons

1. **RViz trajectory visibly departs from diagonal path.** At frame 163,
   the odom trajectory jumps off the physical diagonal and continues
   drifting. This is not a subtle accuracy issue — it is a complete
   localization failure.

2. **Fitness P95 = 7.415 is NOT reasonable.** The original report described
   this as "within reasonable range." In fact, fitness > 1.0 indicates
   the NDT is matching to a wrong target. Fitness ~8 means the source
   and target point clouds have almost no valid correspondence.

3. **Prediction-only 17.4% is NOT acceptable.** The original report did
   not flag this. In a properly functioning system, prediction-only
   should be near 0%. 17.4% means the EKF is rejecting NDT measurements
   because they are clearly wrong.

4. **Processed ratio = 25.6% is FAILING.** Out of 1349 callback frames,
   only 345 were dequeued (1003 dropped by queue overwrite). The system
   is processing less than 1 in 4 input frames.

5. **No ground truth does NOT mean we can ignore obvious drift.** The
   trajectory leaving the physical path is visible in RViz without any
   measurement equipment.

6. **Convergence rate does NOT equal matching correctness.** NDT reports
   "converged" even when aligning to a wrong target. The 99.7% convergence
   rate is meaningless when the target itself is wrong.
